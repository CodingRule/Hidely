Privacy policy

For the Hidely app for Windows and the Hidely browser extension. Last updated 24 November 2026.

In short: nothing leaves your computer. Hidely has no servers, no accounts, no analytics and no advertising. It collects nothing about you, and nothing is sold or shared.

The browser extension

The extension needs to know which tab is in front so it can tell Hidely to protect that browser window. To do that it uses:

WhatWhyWhere it goes
The active tab's address To see whether it is on a site you marked private Checked inside the extension. Not stored or sent anywhere.
The active tab's title and the browser window's position on screen So Hidely can tell which window on your screen to protect Sent only to the Hidely app on the same computer, through the browser's native messaging. Hidely uses them once and does not store them.
The sites you mark private To remember your choice Kept in the browser's own extension storage on your computer.
The tabs you mark private To remember your choice until the browser closes Kept in the browser's session storage, cleared when the browser closes.

The extension makes no network requests. It does not read page contents, form fields, passwords or cookies, and it does not track your browsing history.

The Hidely app

  • It stores your profiles and shortcuts in %LOCALAPPDATA%\Hidely\settings.json. Profiles record program file names such as slack.exe, never window titles or contents.
  • While windows are protected it keeps a small recovery file with window handles, process numbers and process start times, so it can restore windows after a crash. It is deleted when nothing is protected.
  • It makes no network connection by itself. If you choose to check for a new version, it asks github.com for the latest version number. That request carries nothing about you or your windows, and GitHub's own privacy statement applies to it.
  • The optional diagnostic report is shown to you first, saved to your Documents folder only when you press Save, and never uploaded.

Questions

Hidely is open source, so you can check all of the above in the source code. Questions or concerns: open an issue, or report privately as described in the security policy.
